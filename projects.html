AnimeRatings

A full-stack web app for rating and reviewing anime, both by individual season and as a whole series, with watchlists, comments, and show data pulled live from TMDB. Built with a React/Vite frontend and a Node.js/Express/PostgreSQL/Redis backend, containerized with Docker and deployed on a self-managed DigitalOcean server behind nginx with TLS. The project went through a full production security hardening pass (least-privilege database roles, rate limiting, JWT auth with instant revocation, OWASP-style review) and ships through a CI/CD pipeline that runs the full test suite before every automated deploy. Live demo! Check out the code here!

AI Hate Speech Detector

For this project, I collaborated with two others to create two models of hate speech detection and then compare the results. Our data was collected from Kaggle. The first was a naive bayes model which achieved 88% accuracy for hate speech detection. The second model was a randomized forest model from scikit learn which achieved 82% accuracy for hate speech detection. Check it out here!
